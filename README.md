This is an asteroid clone made in Godot for the Terra event. It has all the basic features implemented, and I'm planning on adding even more, such as abilities.
The project makes great use of the `RigidBody2D` nodes in Godot and the `Geometry2D` class in order to interact with and shatter the asteroids.

### How to run
- You can play the game on the its itch page or download the executable from the releases tab
  - (I recommend downloading the binaries from the releases page instead of playing the web version since it's a bit laggy.)

### Controls
- W/S: Thrust forwards/backwards
- A/D: Turn left/right
- Q/E: Apply an impulse to the left/right side of the ship
- Space: Shoot a bullet
- Escape: Open pause menu
